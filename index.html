🥩 목살구이 100g 20g
🐟 생선구이 100g 20g

🍽️ 점심 (11:00)

기본 구성 + 메인 단백질 1가지 선택 = 37g
🥚 단백이 1개 8g
🍚 현미밥 160g 3g
🥗 채소 100g 1g
🫘 두유 190ml 5g

🍪 간식 (16:30)

단백질 20g + 과일 80g = 20g
아래 중 선택
🥤 단백질 음료 1팩 20g
🍫 단백질 바 1개 20g
🥨 단백질 과자 90개 10g
🥛 단백질 우유 200ml 9g
🍶 그릭요거트 100g 11g
🥜 그레놀라 40g 3g
※ 토요일 간식에 과일 대신:
🍪 과자 20g or 🍫 초콜릿 7g → 저녁밥 15g

🍽️ 저녁 (20:00)

기본 구성 + 메인 단백질 1가지 선택 = 23g
(🎯 집중 1주차 협미밥 60g → 50g)
🍚 현미밥 100g 2g
🥗 채소 100g 1g
🔁 식단 치환 기준
곡물
• 현미밥 160g = 통밀모닝빵 80g (약 2개)
• 현미밥 100g = 통밀모닝빵 50g (1~1.5개)

채소 100g 기준
• 상추 6장 + 방울토마토 6개
• 상추 12장
• 방울토마토 12개
• 볶음밥용 채소 (조리 전 100g)
내 데이터 관리
오랜만에 열어도 헷갈리지 않도록, 저장·복원·자동 백업·초기화를 기능별로 나눴어요.
앱 설정
글자 크기와 도서 검색용 API를 설정할 수 있어요. 두 API 키는 이 기기에만 저장됩니다.
글자 크기
도서 API 키
API 키는 이 기기에만 저장되고 백업 파일에는 포함되지 않아요.
정보나루 키
정보나루 키도 백업 파일에는 포함되지 않아요.
내 데이터 보관하기
현재 기록과 BOOKS의 직접 업로드 표지를 하나의 백업 파일로 저장합니다.
저장 위치는 브라우저의 기본 다운로드 폴더입니다. 갤럭시에서는 보통 내 파일 → 다운로드에서 찾을 수 있어요.
아직 이번 접속에서 저장한 백업 파일이 없어요.
백업 파일 불러오기
저장해 둔 JSON 백업 파일을 선택한 뒤 복원합니다. 복원하면 현재 앱 데이터는 백업 파일의 내용으로 교체됩니다.
선택된 파일이 없어요.
예전 버전에서 만든 localStorage 전용 JSON 백업 파일도 복원할 수 있어요.
자동 백업
앱 내부에 임시로 보관하는 비상용 백업입니다. 휴대폰 다운로드 폴더에는 파일이 만들어지지 않아요.
최근 자동 백업을 확인하는 중이에요.
최근 7개만 유지됩니다. 기록/전체 데이터 초기화를 해도 자동 백업은 남아 있어 복원할 수 있습니다. 직접 업로드한 책 표지는 자동 백업에 포함되지 않으므로, 완전한 보관은 위의 백업 파일 저장을 사용해 주세요.
데이터 초기화
필요할 때만 사용하세요. 두 버튼의 삭제 범위가 다릅니다.
기록 데이터 초기화: 날짜별 건강·루틴·독서 기록과 메모만 삭제하고 책 목록·루틴 설정은 유지합니다.
전체 데이터 초기화: 현재 기록·설정·책 목록을 초기화합니다. 자동 백업과 직접 업로드 표지는 복구를 위해 유지됩니다. 자동 백업까지 지우려면 위의 ‘자동 백업 모두 삭제’를 별도로 사용하세요.
수면 직접 기록
새벽 0시~5시 59분에 잠들면 기본적으로 전날 수면으로 기록합니다. 예: 토요일 02:00 취침 → 금요일 기록.
캘린더 검색 칩 선택
체크한 항목만 CALENDAR의 ‘루틴으로 보기’에 표시됩니다. 같은 이름의 루틴은 하나로 묶어 보여요.
