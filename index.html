🥚 단백이 1개 8g
🍚 현미밥 160g 3g
🥗 채소 100g 1g
🫘 두유 190ml 5g

🍪 간식 (16:30)

단백질 20g + 과일 80g = 20g
아래 중 선택
🥤 단백질 음료 1팩 20g
🍫 단백질 바 1개 20g
🥨 단백질 과자 90개 10g
🥛 단백질 우유 200ml 9g
🍶 그릭요거트 100g 11g
🥜 그레놀라 40g 3g
※ 토요일 간식에 과일 대신:
🍪 과자 20g or 🍫 초콜릿 7g → 저녁밥 15g

🍽️ 저녁 (20:00)

기본 구성 + 메인 단백질 1가지 선택 = 23g
(🎯 집중 1주차 협미밥 60g → 50g)
🍚 현미밥 100g 2g
🥗 채소 100g 1g
🔁 식단 치환 기준
곡물
• 현미밥 160g = 통밀모닝빵 80g (약 2개)
• 현미밥 100g = 통밀모닝빵 50g (1~1.5개)

채소 100g 기준
• 상추 6장 + 방울토마토 6개
• 상추 12장
• 방울토마토 12개
